# 🏎️ Velocity Vault

**Velocity Vault** is a high-end, modern, and visually stunning website for premium automotive accessories. Inspired by the sleek aesthetics of brands like Lamborghini and Tesla, it features a dark luxury theme with neon accents and high-performance vibes.

## ✨ Features

- **Luxury Design System**: Dark theme with neon orange accents and glassmorphism.
- **Hero Section**: Stunning parallax background with bold typography and smooth reveals.
- **Interactive Products**: Dynamic product cards with zoom effects and a simulated "Add to Cart" system.
- **Responsive Layout**: Fully optimized for desktop, tablet, and mobile devices.
- **Smooth Animations**: Scroll-triggered reveals, sticky navigation, and custom loading animations.
- **PHP Contact Form**: Functional backend handling with AJAX-like JSON responses.
- **Performance Optimized**: Clean, modular code structure.

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3 (Vanilla), JavaScript (Vanilla)
- **Backend**: PHP
- **Design**: Google Fonts (Outfit & Inter), Font Awesome Icons
- **Assets**: Custom AI-generated automotive imagery
